# Eventora — Smart Event Budget Studio

Premium interactive Streamlit frontend for estimating event budgets.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Features
- Dark premium responsive interface with sidebar navigation
- Overview dashboard
- Event estimate form with event type, city, date, guests, duration and quality
- Category-wise budget breakdown and Plotly chart
- CSV and Excel downloads
- Saved event history and analytics
- Supports birthday, wedding, puberty ceremony, success meet, engagement, baby shower, housewarming, corporate/college and custom functions

## Deploy
Push this folder to GitHub. In Streamlit Community Cloud, select the repository and set the main file path to `app.py`.

## Pricing disclaimer
Baseline prices are illustrative assumptions only. Replace them with actual vendor quotes for each city. The app is currently a transparent estimation calculator, not a trained ML model.
